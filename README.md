# 小璐今天吃什么 (Xiaolu Food Wheel) 🍲

> 一款专为解决“今天吃什么”世纪难题打造的治愈系国风手账美食决策 App。  
> 融合青白瓷陶瓷转盘、吉签盲盒、智能套餐搭配、保姆级食谱与生活打卡手账，让每一餐都充满期待与烟火气。

---

## 🌟 核心特色功能

### 1. 🥮 青白瓷国风大转盘
- **陶瓷美学质感**：双层青白瓷盘面、同心金线刻度虚线环、独立微缩碟盘展示菜品缩略图。
- **朱砂中央抽签钮**：质感立体浮雕“开始抽签”按钮，物理惯性平滑阻尼与精准落点判定。
- **智能过滤**：
  - 支持快捷筛选（全部 / 🥩荤菜 / 🥬素菜 / 🥣靓汤 / ⚡快手）。
  - **避开最近 7 天吃过**机制，防止连日吃腻。

### 2. 🍱 帮我配一餐（智能场景套餐搭配）
- 一键告别单菜纠结，预设四大经典生活场景：
  - **一荤一素一汤**（家常营养均衡标配）
  - **双人丰盛大餐**（两荤一素一汤犒赏周末）
  - **快手独享便餐**（主食 + 荤素快炒）
  - **低卡轻食健康餐**（高蛋白 + 鲜蔬）
- 支持**单个菜品独立重抽**换菜。
- 满意后可**一键将整套大餐所需食材全部打包加入买菜清单**。

### 3. 🎴 每日吉签 · 盲盒翻牌
- 三张朱砂吉签纸牌，随心翻牌体验 3D 卡片翻转动效。
- 揭晓天选吉菜并赠送今日专属美食寄语（如“生活需要烟火，胃口需要抚慰”）。
- 可一键将抽中吉签定为“今日推荐”。

### 4. 📖 保姆级简易食谱详情
- 点击任意菜品即刻唤起保姆级烹饪指南：
  - 烹饪耗时、难度星级、风味定位。
  - **主料与辅料精确克重/份量清单**。
  - **图文按序编号步骤**。
  - **“大厨心得”独家美味秘诀**（如“排骨焯水需冷水下锅”、“大火快炒锁住鲜甜”）。
- 支持一键把食材导入菜篮，或做完后直接拍照打卡。

### 5. 🛒 菜篮子 · 智能买菜清单
- 自动按**“主要食材 / 新鲜蔬菜 / 调味佐料 / 其他原料”**智能归类。
- 支持采购过程**划线核销勾选**。
- 支持快速手动添加临时自选商品。
- **一键复制清单文本**（贴心排版，方便直接发至微信给去采购的家人或伴侣）。

### 6. 📷 美食日记与拍立得手账分享
- 记录日期、菜名、美味星级评分、心得笔记与成品照片。
- **拍立得手账卡片**：自动生成带有和纸胶带装饰、朱砂印章、手写字体与拍立得相框的美食卡片，支持一键复制分享文案。

### 7. 🔒 本地优先与数据备份
- 数据全部保存在设备本地（LocalStorage），隐私无忧。
- 支持将全量菜谱、历史打卡日记、待买清单**一键导出为 JSON 备份文件**与**恢复导入**。

## 🛠️ 技术栈

- **框架**：React 19 + Vite 6
- **图标**：`@phosphor-icons/react`
- **移动端容器**：Capacitor 8 (支持 Android 打包与原生文件导出保存)
- **样式**：纯原生现代化 CSS（CSS Variables + 3D Transform + 柔和毛玻璃与纸纹渲染）

## 🚀 本地开发与构建

### 1. 安装依赖
```bash
pnpm install
# 或者使用 npm
npm install
```

### 2. 启动本地开发服务
```bash
npm run dev
# 或直接通过 Node 启动
node .\node_modules\vite\bin\vite.js --host 127.0.0.1
```
启动后在浏览器打开 `http://127.0.0.1:5173/` 即可体验。

### 3. 生产环境打包
```bash
npm run build
```
构建产物将输出在 `dist/` 目录下。

### 4. 移动端 (Capacitor / Android)
```bash
# 同步 Web 资源到 Android 工程
npx cap copy
npx cap sync

# 打开 Android Studio 进行调试或打包 APK
npx cap open android
```
